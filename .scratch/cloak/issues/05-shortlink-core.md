# 05 — shortlink-core(短链核心:创建 / 关联域名 / 跳转 / 未命中 / 停用删除)

**What to build:** 创建短链(自定义或自动短码、选择关联域名、目标任意协议、默认 302 可配 301);访问"域名/短码"命中→跳转、未命中/停用/逻辑删除→404;`(域名, 短码)` 唯一约束;同一短码跨域名指向不同目标成立;短链配额校验接通。

**Blocked by:** 02, 04

**Status:** ready-for-agent

- [ ] 创建短链:目标为任意协议文本,拒绝 CRLF 等控制字符;关联租户的一个或多个 active 域名
- [ ] 自定义短码(校验合法)或留空自动生成(字符集去 `0/O/1/l/I`,长度取租户配置,默认 6)
- [ ] 同一域名下短码重复创建被拒(唯一约束);同一短码关联不同域名、指向不同目标成立
- [ ] 访问 active 域名下命中短链 → 默认 302 跳转目标;短链配置 301 时返回 301
- [ ] 未命中 / 停用短链 / 逻辑删除短链 → 404
- [ ] 短链数达到配额上限时拒绝创建,并返回当前用量/上限
