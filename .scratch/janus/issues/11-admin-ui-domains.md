## Comments

- 已实现 `web/src/views/domains/DomainsView.vue`:列表展示域名(fqdn 可复制)、来源(自有域名/平台默认域名)、状态(待激活/已激活/校验失败/已停用)、证书状态(待签发/已签发/失败)、激活/创建时间;10 秒轮询自动刷新,便于观察 DNS 校验与证书签发进展。
- 添加自有域名弹窗(提示先配 DNS A/AAAA 指向本服务器);400/403(域名配额超限,message 含用量/上限)/409(域名已被占用)按后端 `{code,message}` 分别展示。
- 操作:手动重检(202)、停用/恢复(平台默认域名可停用/恢复,契约允许)、删除(自有域名;存在未删除短链 → 409 提示"请先移除该域名下关联的未删除短链";平台默认域名禁用删除并提示只能停用)。
- 用到的契约端点:GET /api/domains、POST /api/domains、POST /api/domains/{id}/recheck、PATCH /api/domains/{id}、DELETE /api/domains/{id}。
- 待联调:需主会话在 web/ 下 `pnpm install && pnpm dev` 后用真实后端验证添加/重检/停用/删除与 409 分支。
