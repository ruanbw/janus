# 平台默认域名采用按子域逐个签发(而非泛域名证书)

平台为每个租户自动提供一个"<前缀>.<平台域名>"的默认域名,依赖 DNS 上的泛域名解析"*.<平台域名>"指向本服务器。证书方案采用与自有域名一致的 on-demand + HTTP-01 逐个签发,而非签发一张"*.<平台域名>"的泛域名证书。

选择按子域签发而非泛域名证书:前者与 ADR-0002 的 on-demand 授权机制完全一致,授权端点按"<前缀>.<平台域名> 且前缀属于已验证、未封禁的租户"放行,零额外依赖;泛域名证书需要 DNS 托管商 API 凭据与 Caddy 的 DNS-01 插件,且所有租户共享同一张证书,续期与吊销边界不清晰。

已知限制:按子域签发受 Let's Encrypt"每注册域名每周 50 张证书(含续期)"限制,该额度按平台域名聚合;当活跃子域规模接近该上限时应迁移到泛域名证书方案。
